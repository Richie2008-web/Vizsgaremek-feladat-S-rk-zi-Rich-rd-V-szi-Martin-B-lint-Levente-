2. A KKK elvárásainak kijegyzetelése 
- Életszerű, valódi problémára adjon megoldást Olyan felhasználói igényt kell lefednie, ami ténylegesen előfordul a mindennapokban. 
- Legyen adatbázisa, és valós adatkezelést valósítson meg CRUD műveletek: létrehozás, módosítás, törlés, lekérdezés. 
- RESTful architektúra 
- Backend: API végpontok, adatkezelés 
- Frontend: kliensoldali felület 
- A két rész külön komponens, külön fejlesztési logikával 
- A kliens működjön asztali és mobil eszközön is Reszponzív felület, mobilbarát UI. 
- Tiszta kód elvei (Clean Code) 
- Olvasható, logikus kódszerkezet 
- Moduláris felépítés 
- Érthető változónevek 
- Kommentek, dokumentált funkciók 
- Dokumentáció készítése 
- Rendszerleírás 
- API dokumentáció 
- Telepítési útmutató 
- Felhasználói útmutató 
- Tesztelés 
- Backend unit tesztek 
- Frontend funkcionális tesztek 
- Teszteredmények csatolása 

 

3. Témaötletelés 
- A. Edzésnapló weboldal:  
    Felhasználók rögzíthetik az edzéseiket, súlyokat, ismétléseket, gyakorlatokat. Statisztikák, fejlődéskövetés, grafikonok.  

 - B. Időpontfoglaló weboldal: 
    Szolgáltatók időpontokat adnak meg, ügyfelek foglalnak. Foglalás módosítása, törlése, visszaigazolás.
